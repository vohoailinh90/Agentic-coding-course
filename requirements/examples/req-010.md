# REQ-010

## Requirement

Implement idempotent payment processing for Kafka retry/redelivery so a message can never create a duplicate external charge, while preserving retryability after partial failures.

This fixture is duplicated in `evals/routing-cases.yaml` so it can also be tested interactively. Expected routing lives only in `evals/expected-routing.yaml` (evaluator-only oracle) — do not open it before classifying.
